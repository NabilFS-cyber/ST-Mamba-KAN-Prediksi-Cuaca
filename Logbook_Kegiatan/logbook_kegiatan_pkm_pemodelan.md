# Kegiatan

Berikut adalah rekam jejak saintifik tahap perancangan arsitektur, pelatihan, hingga evaluasi operasional model AI (Fase 6 hingga 9). Logbook ini telah diaudit dan disinkronkan dengan dokumen `MASTER_CHANGELOG_EVOLUTION` dan `PROPOSAL_VS_IMPLEMENTATION`, serta disusun berurutan berdasarkan lini masa pelaporan (Akhir Juli hingga Pertengahan Agustus 2026).

| Tanggal | Kegiatan |
| :--- | :--- |
| **26-07-2026** | **Integrasi Graph Attention Network (GAT):**<br>Melakukan pemetaan koordinat spasial longitude dan latitude 5 stasiun pengamatan (Soekarno-Hatta, Tanjung Priok, Kemayoran, Citeko, Klimatologi Jabar). Modul GAT disuntikkan di awal lapisan model untuk menangkap konektivitas spasial curah hujan antar-stasiun BMKG secara topologis sebelum diproses oleh lapisan temporal. |
| **28-07-2026** | **Pembuatan Arsitektur GAT-Mamba-KAN:**<br>Merakit dan menjalankan inti arsitektur dengan memadukan blok GAT, *Selective State Space Model* (Mamba S6), dan *Kolmogorov-Arnold Network* (KAN). Hasil pengujian komputasi membuktikan bahwa penggabungan *State-of-the-Art* ini sanggup mengekstraksi dependensi temporal historis serta permodelan fungsi non-linear data cuaca dengan latensi *feed-forward* yang sangat efisien. |
| **31-07-2026** | **Dual-Head Multi-Task & Fungsi Loss:**<br>Menerapkan pendekatan *Multi-Task Learning* dengan dua luaran (regresi dan klasifikasi). Pelatihan dioptimasi menggunakan dua fungsi *loss* secara simultan: *Huber Loss* untuk mengurangi nilai error regresi intensitas hujan, dan *Ordinal Cost Focal Loss* untuk optimasi probabilitas klasifikasi status siaga. Kurva *loss* menunjukkan pola konvergensi yang sinkron sejak iterasi awal. |
| **03-08-2026** | **Pelatihan Model (300 Epochs):**<br>Menuntaskan pelatihan komprehensif pada arsitektur GAT-Mamba-KAN selama 300 iterasi (*epochs*). Penerapan algoritma penjadwalan *Cosine Annealing Warm Restarts* terbukti memuluskan metrik validasi, yang secara bertahap terus menurun hingga mencapai titik konvergensi akhir pada nilai *Root Mean Square Error* (RMSE) terendah yakni 17.07 mm. |
| **06-08-2026** | **Dashboard Evaluasi:**<br>Mengukur kinerja model secara komprehensif melalui *Dashboard Evaluasi 8-Panel*. Arsitektur dievaluasi secara serentak mencakup stabilitas konvergensi, komparasi metrik klasifikasi multi-aspek, uji ablasi, ketahanan prediksi terhadap waktu (*lead-time*), hingga analisis *Explainable AI* (XAI) untuk transparansi bobot fitur cuaca. |
| **09-08-2026** | **Konsol Sirine Alarm:**<br>Mengevaluasi dan menata ulang logika ambang batas pemicu alarm status siaga pada antarmuka konsol evaluasi. Alarm diprogram secara akurat untuk memicu sinyal peringatan aktif secara spesifik ketika tingkat probabilitas prediksi luaran dari cabang klasifikasi melampaui nilai ambang (*threshold*) 89.77%. |
| **11-08-2026** | **Simulasi Prediksi Real-Time:**<br>Menguji kemampuan antisipatif model melalui kerangka simulasi grafis *sliding window* 14-hari berbasis data deret waktu yang terus bergeser. Kurva pengujian membuktikan bahwa garis prediksi model secara presisi mampu beradaptasi dan mengikuti pola puncak curah hujan dari data observasi aktual secara dinamis. |
| **13-08-2026** | **Perbandingan dengan Model Baseline:**<br>Melakukan eksperimen perbandingan nilai regresi antara arsitektur usulan dan arsitektur literatur standar (*Fair Baselines*). Uji komparasi ini membuktikan validasi hipotesis, di mana arsitektur hibrida GAT-Mamba-KAN mencapai tingkat error terendah (RMSE 17.07 mm) secara *Apple-to-Apple* dibandingkan kinerja Mamba-MLP, CNN-GRU, dan CNN-LSTM. |
| **15-08-2026** | **Evaluasi Ablasi & Komparasi:**<br>Melakukan kompilasi performa deteksi tingkat siaga berdasarkan metrik tingkat Akurasi Total (*Total Accuracy*) dan *Critical Success Index* (CSI). Model GAT-Mamba-KAN terbukti secara signifikan mengungguli seluruh model referensi (mencapai Akurasi Total 88.02% dan CSI >80%) dalam kapabilitasnya mendeteksi curah hujan ekstrem. |
